# Security policy

## Reporting a vulnerability

Do not publish an exploitable security issue in a public discussion. Use GitHub's private vulnerability reporting for this repository. Include the affected version, operating system, reproduction steps, and expected impact.

## Operating boundary

This tool is defensive and local-first. Run it only on systems and data you are authorized to inspect. Review commands that request elevated privileges before approving them.

Version 0.1 receives security fixes on the latest release line.
